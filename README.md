# Info Wisata Daerah

## Deskripsi
Info Wisata Daerah merupakan aplikasi mobile
untuk memberikan informasi mengenai tempat wisata
di suatu daerah.

## Fitur Aplikasi
1. Menampilkan daftar tempat wisata.
2. Menampilkan nama dan lokasi wisata.
3. Menampilkan detail deskripsi wisata.
4. Menampilkan harga tiket masuk.
5. Menampilkan jam buka wisata.
6. Memberikan label GRATIS jika harga tiket Rp0.
7. Navigasi dari daftar ke halaman detail.
